1. Project Title / Headline
HR Analytics Dashboard: Employee Demographics & Workforce Insights
A dynamic and interactive Power BI dashboard designed to analyze employee data, focusing on demographics, education, job roles, and workplace satisfaction. It helps organizations understand workforce distribution and improve HR decision-making.
2. Short Description / Purpose
This dashboard provides a comprehensive analysis of employee data, including age groups, gender distribution, education levels, and job roles. It enables HR teams to monitor workforce trends, evaluate employee satisfaction, and make data-driven decisions to improve organizational performance.
3. Tech Stack
The dashboard was built using the following tools and technologies:
Power BI Desktop – Main data visualization and dashboard creation tool
Power Query – Used for data cleaning, transformation, and preprocessing
DAX (Data Analysis Expressions) – Used to create calculated measures and KPIs
Data Modeling – Relationships established between employee datasets
File Format – .pbix for development and .png for dashboard preview

The dataset consists of employee-related information such as:
